# Sayan Duari — Portfolio

A responsive, dark editorial-style developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser.

## Before publishing
- Review the project descriptions and accuracy metric before publishing.
- The resume PDF is included in `assets/Sayan_Duari_Resume.pdf` and linked from the hero and contact sections.

## Publish
You can deploy this folder using GitHub Pages, Netlify, or Vercel. For GitHub Pages, push the files to a repository and enable Pages in the repository settings.
